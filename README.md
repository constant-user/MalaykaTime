# MalaykaTime 🌿⏱

**MalaykaTime** — локальное веб-приложение для учёбы в стиле YPT: таймер фокуса,
календарь-планер, задачи на любые даты и статистика. Один HTML-файл, работает
полностью офлайн, без серверов, аккаунтов и аналитики.

## Возможности

- ⏱ **Таймер** — отсчёт (15/25/50/90 мин или свой) и секундомер с круговым индикатором,
  сигнал по окончании, короткие/длинные перерывы, горячая клавиша `Пробел`.
- 🗓 **Календарь** — месяц с отметками времени и задач; задачи и время можно добавлять
  на **прошедшие** и **будущие** даты, в том числе на «задние» и «передние» числа
  соседних месяцев (они кликабельны в сетке).
- ✅ **Задачи** — план на день с фильтрами: все / сегодня / предстоящие / просроченные /
  выполненные.
- 📊 **Статистика** — время за сегодня и 7 дней, серия дней, тепловая карта 5 недель,
  цель дня, задачи по датам, разбивка по предметам. Ручные записи времени на прошлые
  даты учитываются везде.
- 📦 **Перенос данных** — резервная копия скачивается файлом JSON или копируется в буфер
  обмена; на другом устройстве — загрузка файла или вставка из буфера. Прогресс
  переносится полностью.

## Запуск

Никакой установки не нужно:

1. Скачайте/скопируйте папку репозитория.
2. Двойной клик по `index.html` — приложение откроется в браузере.
3. (опционально) Создайте ярлык `index.html` на рабочем столе — получите отдельное
   окно приложения, как в мобильной версии.

## Где хранятся данные

Все данные (сессии, задачи, настройки) сохраняются **только локально** в вашем
браузере (`localStorage`, ключ `malaykatime.v1`). Сетевых запросов нет вообще:
нет CDN, шрифтов из интернета, трекеров и облаков. Для переноса на другое ПК
используйте «Настройки → Перенос данных».

## Технологии

Чистые HTML + CSS + JavaScript в одном файле. Без фреймворков, без сборки, без
зависимостей. Современный браузер (Edge / Chrome / Firefox / Safari).
